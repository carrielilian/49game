## 5. 关键业务规则

1. 当前文档只表达最新有效规则，历史变化全部进入需求变更台账。
2. 合同合作内容提交后不可取消；对应合同金额仍可调整，但不得低于已付款金额。
3. 已付款项不得小于已保存金额，也不得大于合同对应金额。
4. 付款设置不再人工选择有无预付；预付状态由合同约定与已付款项自动判断。
5. 查询只影响列表展示和查询总计；收入、退款结算覆盖当前业务类型全部未结算数据。
6. 自有、外部渠道退款分别使用本系统对应渠道公式；退款均不扣渠道费。
7. 游戏运营状态包含未上线、已上线、已下线；只有已上线游戏参与新数据拉取。
8. 付款申请、结算函和已付款历史使用申请时快照，后续主数据修改不回写历史结果。
