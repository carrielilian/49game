# 代理游戏财务原型需求变更台账

> 当前基线：代理游戏财务原型 V1.0
> 建立时间：2026-11-03
> 文档职责：记录需求为什么变化、何时变化、影响什么；不得替代当前需求说明和主规格。

## 1. 使用规则

1. 需求编号使用 `AGF-提出日期-当日三位顺序号`，编号永久不变。
2. 原始需求保留用户业务原意；最终规则使用可验收的业务语言，不写代码实现细节。
3. 首次提出、确认、实现和验收是四个独立时间，不得用 Git 提交时间代替需求提出时间。
4. 无法从原对话或 Git 证据确认的旧时间，统一写“时间待确认”，禁止推测。
5. 历史记录只追加，不删除、不覆盖。规则变化时新增需求，并在旧需求中写明替代关系。
6. 当前有效规则以 [`agent-game-finance-requirements.md`](./agent-game-finance-requirements.md)、[主规格](../../prototypes/agent-game-finance/.spec/spec.html)、[`ui-spec.md`](./ui-spec.md) 和当前页面批注为准。
7. `conversation-memory.md` 仅用于恢复上下文；发生冲突时不能作为正式需求依据。
