# 标记付款抽屉

## 字段

| 字段 | 规则 |
|------|------|
| 游戏ID、游戏名称 | 只读。**初始**：打开时展示当前付款记录对应游戏 |
| 待付款金额 | 只读；￥ + 千分位。**初始**：打开时展示该笔记录的待付款金额 |
| 实际付款金额 * | 可编辑；￥；必填；≥ 0；精确至小数点后两位。**初始**：见下方「金额初始计算」 |
| 实际付款美金 | 可编辑；$；选填；≥ 0。**初始**：见下方「金额初始计算」 |
| 分成付款公司 | 只读；读取本笔【申请付款】成功时冻结的分成付款公司快照；申请后修改【付款设置】不影响本笔记录 |
| 收款信息 * | 多行；必填。**初始**：该笔记录已保存过则显示已保存内容；否则默认填入归属厂商银行五字段 |
| 备注 | 选填。**初始**：该笔记录已保存过则显示已保存内容；否则为空 |

## 金额初始计算

**每次打开**【标记付款】，均使用本笔【申请付款】成功时冻结的快照值计算金额并写入输入框，不读取当前游戏、合同或【付款设置】中的最新数据；写入后仍可手动修改。

### 参与变量

| 变量 | 来源 |
|------|------|
| 待付款金额 | 本笔【申请付款】成功时冻结的待付款金额 |
| 预付分成款 | 本笔【申请付款】快照中的预付分成款 |
| 剩余未抵扣分成款 | 本笔【申请付款】快照中的申请时剩余未抵扣分成款 |
| 合同支付币种 | 本笔【申请付款】快照中的合同支付币种 |
| 付款币种 | 本笔【申请付款】快照中的付款币种 |
| 汇率 | 本笔【申请付款】快照中的汇率（对应申请时填写的汇率取值时间） |

### 中间量

| 名称 | 计算方式 |
|------|----------|
| net | 待付款金额 − 剩余未抵扣分成款；若 ≤ 0 则按 0 |
| usdNet | 待付款金额 ÷ 汇率 − 剩余未抵扣分成款；若 ≤ 0 则按 0 |

### 三种情况

| 情况 | 条件 | 实际付款金额（￥） | 实际付款美金（$） |
|------|------|-------------------|------------------|
| 1 | 预付分成款 ≤ 0 | ＝ 待付款金额 | 付款币种＝美金时 ＝ 待付÷汇率；否则空 |
| 2 | 预付分成款 > 0，合同支付币种 ＝ 人民币 | ＝ net | ＝ net ÷ 汇率 |
| 3 | 预付分成款 > 0，合同支付币种 ＝ 美金 | ＝ usdNet × 汇率 | ＝ usdNet |

全额抵扣后 net / usdNet 可能为 0，此时实际付款金额显示 **0.00**。

## 按钮

| 按钮 | 行为 |
|------|------|
| 取消 | 关闭，不保存 |
| 标记已付款 | 校验通过后保存并改状态为已付款；关闭抽屉；绿色「提交成功」 |

校验失败：字段下红字 + 红 Toast「请完善所有信息」。
