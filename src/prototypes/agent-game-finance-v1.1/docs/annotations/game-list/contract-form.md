# 合同管理表单

## 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 游戏编号 / 游戏名称 | — | 只读 |
| 合同编号 | 必填 | |
| 支付币种 | 必填 | 人民币 / 美金；**首次保存前**可单选，保存后再次进入仅展示不可改；选定后下方金额输入框显示对应币种符号 |
| 合同金额 | 必填 | 两位小数，不小于 0 |
| 合作内容 | 必填 | 至少勾选一项：游戏代理金、预付分成款、委托开发费；已提交的项目保持勾选并置灰，不可取消；未提交的新勾选项在本次提交前可取消 |
| 游戏代理金 | 勾选代理金时必填 | 合同约定金额，勾选后才显示；不能小于已付游戏代理金 |
| 预付分成款 | 勾选预付分成款时必填 | 合同约定金额，勾选后才显示；不能小于已付预付分成款 |
| 委托开发费 | 勾选委托开发费时必填 | 合同约定金额，勾选后才显示；不能小于已付委托开发费 |
| 补充说明 | 选填 | |
| 合作状态 | 必填 | 合作中 / 合作终止；默认合作中 |

已提交项目仅通过保持勾选且禁用的状态表达，不额外显示说明文字。首次维护或本次新增但尚未提交的合作内容仍可取消，取消后清空本次尚未提交的对应合同约定金额。

## 保存规则

必填未齐、尝试取消已提交合作内容，或合同约定金额小于对应已付款金额 → 字段红色提示 + 「请完善所有信息」。
保存成功 → 关闭抽屉 + 绿色「提交成功」；合同变更写入操作记录。

支付币种仅在本抽屉维护，影响列表金额展示币种。**首次**打开且尚未保存过支付币种时可选择；**保存成功后**再次进入仅展示，不可修改。
