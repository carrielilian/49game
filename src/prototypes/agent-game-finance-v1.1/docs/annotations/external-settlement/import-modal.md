# 数据导入弹窗

## 上传报表

报表字段：**收入时间、渠道、游戏ID、游戏名称、厂商名称、待结算金额**。点击上传区模拟解析。

外部渠道允许：小米、荣耀、华为、爱九游、vivo、oppo、B站、TapTap、应用宝、ios、Steam、WeGame、穿山甲广告 iOS、穿山甲广告安卓、mumu、雷电。新增渠道也支持使用英文标识导入：WeGame、csj(iOS)、csj(Android)、mumu、LDPlayer；导入后统一显示中文渠道名称。

## 校验

- 校验按“文件 → 表头 → 全表数据 → 重复数据”的顺序执行；高优先级失败后不继续后续校验。
- 文件格式错误提示「格式错误，仅支持 xlsx、xls、csv」；文件超过 5MB 提示「文件大小不得超过5MB」。
- 缺少、重复或名称错误的必填表头提示「导入文件字段格式错误」。
- 数据行号包含表头，第一条数据为第2行；同类错误的多个行号用“、”连接。
- 收入时间不符合 `yyyy-mm`，或收入时间大于等于当前月份，提示「第n、m行收入时间错误」。
- 游戏ID不存在或不属于当前业务类型，提示「第n、m行游戏ID不存在」。
- 渠道不在允许范围，提示「第n、m行渠道不存在」。
- 待结算金额不是数字或超过两位小数，提示「第n、m行待结算金额格式错误」。
- 游戏名称、厂商名称和外部渠道结算公式不参与导入校验。
- 任一校验失败时，在上传区域下方显示红字，不展示导入数据。
- 原型演示：每次打开弹窗后的首次有效文件上传，展示按行号汇总的全表数据错误；再次上传后进入正常校验和成功预览流程。

## 重复校验

按“收入时间 + 渠道 + 游戏ID”判断主列表及本次报表内是否已有同维度数据。

| 情况 | 表现 |
|------|------|
| 与主列表重复 | 显示上传文件中的冲突行号，例如「第2、5行数据存在重复内容」 |
| 文件内部重复 | 显示同组重复数据涉及的全部行号，例如「第3、8行数据存在重复内容」 |
| 无重复 | 显示上传成功后的数据列表 |

## 上传成功列表

第一行为“总计”，只汇总待结算金额。其余行字段与上传报表一致：

收入时间、渠道、游戏ID、游戏名称、厂商名称、待结算金额。

只有全部校验通过后才显示列表。底部仅保留【取消】与【确认导入】。确认导入后关闭弹窗、整批写入主列表最上方，新增记录的结算收入、结算公式和结算时间显示“-”。
