# 游戏付款列表

## 做什么

展示游戏维度付款申请与付款结果；未付款可标记付款，已付款可查看详细信息。

## 各列含义

| 列 | 说明 |
|----|------|
| 游戏ID / 游戏名称 | 左边游戏 ID，右边游戏名称；读取最新游戏资料 |
| 厂商ID / 厂商名称 | 单行显示“ID / 名称”；读取最新厂商资料 |
| 待付款金额 | 申请时账户余额；￥ + 千分位 |
| 实际付款金额 | ￥ + 千分位；已记录为 0 时显示「￥0.00」，仅未填时显示「-」 |
| 实际付款美金 | 显示在实际付款金额右侧；$ + 千分位；已记录为 0 时显示「$0.00」，仅未填时显示「-」 |
| 付款状态 | 见 **付款状态列** 批注 |
| 申请时间 / 付款时间 | 同一列上下两行；精确到秒；未付款时付款时间「-」 |
| 操作 | 见各操作批注 |

主列表不使用结算函快照中的游戏、厂商名称；主数据修改后，列表同步显示最新资料。结算函仍读取申请付款时保存的快照。
