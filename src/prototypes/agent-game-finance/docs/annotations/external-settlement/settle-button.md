# 结算

## 做什么

结算当前查询结果中的全部未结算收入记录，不区分数据来自系统拉取还是文件导入。

## 规则

| 情况 | 页面表现 |
|------|----------|
| 当前列表无待结算数据 | 按钮禁用 |
| 自有渠道缺少自有渠道公式，或任一外部渠道缺少外部渠道公式 | 整批不结算，提示「{游戏ID}缺少结算公式」；多个游戏ID去重后用「、」连接 |
| 任一记录校验或计算失败 | 整批不结算，提示「结算失败，本次数据均未结算：{原因}」 |
| 结算成功 | 写入结算收入和结算时间，绿色提示「结算成功」 |

点击后先校验本次全部未结算记录，全部通过才一次性写入；禁止部分记录成功、部分记录失败。失败后所有记录保持未结算，【结算】仍可点击，修正数据后可重试。
