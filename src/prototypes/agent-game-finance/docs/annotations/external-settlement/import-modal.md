# 数据导入弹窗

## 上传报表

报表字段：**收入时间、渠道、游戏ID、游戏名称、厂商名称、待结算金额**。点击上传区模拟解析。

外部渠道仅允许：小米、荣耀、华为、爱九游、vivo、oppo、B站、TapTap、应用宝、ios。

## 重复校验

按“收入时间 + 渠道 + 游戏ID”判断主列表及本次报表内是否已有同维度数据。

| 情况 | 表现 |
|------|------|
| 单个游戏重复 | 红色提示“{游戏ID}数据重复上传” |
| 多个游戏重复 | 游戏ID用“、”连接，例如“4001、4002数据重复上传” |
| 无重复 | 显示上传成功后的数据列表 |

## 上传成功列表

第一行为“总计”，只汇总待结算金额。其余行字段与上传报表一致：

收入时间、渠道、游戏ID、游戏名称、厂商名称、待结算金额。

底部仅保留【取消】与【确认导入】。确认导入后关闭弹窗、写入主列表，新增记录的结算收入和结算时间显示“-”。
