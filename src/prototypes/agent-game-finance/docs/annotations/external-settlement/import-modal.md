# 数据导入弹窗

## 上传报表

报表字段：**收入时间、渠道、游戏ID、游戏名称、厂商名称、待结算金额**。点击上传区模拟解析。

外部渠道仅允许：小米、荣耀、华为、爱九游、vivo、oppo、B站、TapTap、应用宝、ios、Steam。

## 校验

- 文件仅支持 xlsx、xls、csv，大小不超过 5MB，不限制数据条数。
- 缺少或重复必填表头时提示「导入文件字段格式错误」。
- 数据错误按类型提示：「收入时间格式错误」；「{游戏ID}游戏ID不存在」，多个游戏ID用“、”连接；「{渠道}渠道不存在」，多个渠道用“、”连接；「待结算金额格式错误」。
- 游戏名称、厂商名称和外部渠道结算公式不参与导入校验。
- 任一校验失败时，在上传区域下方显示红字，不展示导入数据。
- 原型演示：每次打开弹窗后的首次有效文件上传，固定显示带示例值的“{游戏ID}游戏ID不存在”“{渠道}渠道不存在”和“待结算金额格式错误”三条红字；再次上传后进入正常校验和成功预览流程。

## 重复校验

按“收入时间 + 渠道 + 游戏ID”判断主列表及本次报表内是否已有同维度数据。

| 情况 | 表现 |
|------|------|
| 单个游戏重复 | 红色提示“{游戏ID}数据存在重复内容” |
| 多个游戏重复 | 游戏ID用“、”连接，例如“100001、100002数据存在重复内容” |
| 无重复 | 显示上传成功后的数据列表 |

## 上传成功列表

第一行为“总计”，只汇总待结算金额。其余行字段与上传报表一致：

收入时间、渠道、游戏ID、游戏名称、厂商名称、待结算金额。

只有全部校验通过后才显示列表。底部仅保留【取消】与【确认导入】。确认导入后关闭弹窗、整批写入主列表，新增记录的结算收入和结算时间显示“-”。
