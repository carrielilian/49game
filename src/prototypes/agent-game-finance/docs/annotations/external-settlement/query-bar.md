# 查询栏

## 做什么

缩小主列表显示范围。

- **业务类型**：在「游戏盒」与「快爆」两套数据间切换。
- **收入时间**：按月范围筛选，默认近两个月（上个月 + 当前月）。
- **游戏ID / 游戏名称、厂商ID / 厂商名称**：各使用一个搜索框；厂商框可按ID或名称匹配，与上述条件同时生效。

## 不同情况怎么展示

| 情况 | 页面表现 |
|------|----------|
| 首次进入 | 默认业务类型「游戏盒」，收入时间为近两个月 |
| 无匹配数据 | 表格空状态 |

收入数据可以通过【数据拉取】或【数据导入】写入同一张主列表。只要当前查询范围存在未结算记录，【结算】即可点击。
