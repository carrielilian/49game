# 外部收入列表

## 做什么

展示已导入的外部渠道待结算与已结算收入记录。先【数据导入】，再在主列表点击【结算】。

## 各列含义

| 列 | 说明 |
|----|------|
| 收入时间 | 报表中的收入月份 |
| 游戏ID / 游戏名称 | 左边游戏 ID，右边游戏名称 |
| 厂商编号、厂商名称 | 归属厂商，分两列 |
| 渠道 | 小米、荣耀、华为、爱九游、vivo、oppo、B站、TapTap、应用宝、ios |
| 待结算金额 | 人民币 + 千分位 |
| 结算收入 | 未结算显示“-”；结算后显示人民币 + 千分位 |
| 结算公式 | 该游戏外部渠道公式；未配置显示“-” |
| 结算时间 | 未结算显示“-”；结算后显示操作时间 |
| 申请付款状态 | 见“申请付款状态列”批注 |
