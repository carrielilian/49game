# 收入结算列表

## 做什么

在同一主列表展示系统拉取和文件导入的待结算、已结算收入记录。

## 各列含义

| 列 | 说明 |
|----|------|
| 收入时间 | 报表中的收入月份 |
| 游戏ID / 游戏名称 | 左边游戏 ID，右边游戏名称 |
| 厂商ID / 厂商名称 | 归属厂商，单行显示“ID / 名称” |
| 渠道 | 系统拉取显示汇总渠道“游戏盒 / 快爆”；文件导入显示实际第三方渠道 |
| 待结算金额 | 人民币 + 千分位 |
| 结算收入 | 未结算显示“-”；结算后显示人民币 + 千分位 |
| 结算公式 | 未结算显示“-”；结算成功后，自有渠道显示本次冻结的自有渠道公式，外部渠道（系统拉取、文件导入）显示本次冻结的外部渠道公式 |
| 结算时间 | 未结算显示“-”；结算后显示操作时间 |
| 申请付款状态 | 见“申请付款状态列”批注 |
