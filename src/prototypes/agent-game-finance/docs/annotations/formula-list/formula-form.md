# 结算公式表单

## 顶部只读

游戏编号 / 游戏名称、厂商编号、厂商名称、当前已生效结算公式（两行；未配置时为「-」）。

## 自有渠道结算公式

| 字段 | 必填 | 说明 |
|------|------|------|
| 扣税点 | 自动 | 默认跟随发票；移除原“跟随发票 / 自定义”模式选择行，直接显示映射结果 |
| 渠道费 | 必填 | 0–100 整数，带 % 后缀 |
| 分成 | 必填 | 0–100 整数，带 % 后缀 |

## 外部渠道结算公式

| 字段 | 必填 | 说明 |
|------|------|------|
| 扣税点 | 自动 | 默认跟随发票；移除原“跟随发票 / 自定义”模式选择行，直接显示映射结果 |
| 渠道费 | 必填 | 0–100 整数，带 % 后缀 |
| 分成 | 必填 | 0–100 整数，带 % 后缀 |

### 扣税点规则

自有、外部渠道均按归属厂商“发票信息”映射为只读扣税点；发票为“其他”时显示百分数输入框。

| 发票信息 | 扣税点 |
|----------|--------|
| 增值税专用发票（6%） | 0% |
| 增值税专用发票（3%） | 3.36% |
| 增值税专用发票（1%） | 5.6% |
| 普通发票 | 6.72% |
| 其他 | 手输 |

## 保存规则

任一必填未填 → 红色提示 + 「请完善所有信息」。  
保存成功 → 关闭抽屉 + 绿色「提交成功」；列表公式列与操作记录同步更新。
