# 数据拉取表单

顶部只读显示游戏ID / 游戏名称和厂商名称。

| 业务类型 | 自有渠道 | 外部渠道 |
|------|------|------|
| 游戏盒 | 游戏盒：手游付费、手游内购、手游广告 | 快爆：手游付费、手游内购、小游戏广告 |
| 快爆 | 快爆：手游付费、手游内购、小游戏广告 | 游戏盒：手游付费、手游内购、手游广告 |

每组具体渠道上方使用黑色加粗文字显示对应汇总渠道。游戏盒业务的自有渠道显示“游戏盒”、外部渠道显示“快爆”；快爆业务反向。

每行由勾选框、渠道名称、渠道游戏ID输入框组成。勾选后渠道游戏ID必填；多个ID使用英文半角逗号「,」分隔，保存时去除各项首尾空格并过滤空段。

文件导入的外部渠道不在【数据拉取】抽屉展示，通过【收入结算】的【数据导入】接入。

抽屉底部主按钮显示【确定】，点击后执行原保存校验。
