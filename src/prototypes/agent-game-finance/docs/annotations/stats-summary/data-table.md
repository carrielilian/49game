# 收入汇总列表

## 做什么

按所选维度汇总展示截至当前的合同付款、结算净收入与实际付款累计值，不按月份拆分。

## 各维度列

| 维度 | 列 |
|------|-----|
| 游戏 | 游戏ID / 游戏名称、合同已付款金额、总收入、累计实际付款金额 |
| 渠道 | 渠道、合同已付款金额、总收入、累计实际付款金额 |
| 厂商 | 厂商ID / 厂商名称、合同已付款金额、总收入、累计实际付款金额 |

渠道维度中，系统拉取的收入和退款按汇总渠道“游戏盒 / 快爆”聚合；文件导入的收入保留实际外部渠道名称。列表、筛选及导出使用相同渠道口径。

## 金额含义

| 列 | 说明 |
|----|------|
| 合同已付款金额 | 游戏、厂商维度：合同已付游戏代理金 + 已付预付分成款 + 已付委托开发费，按币种分别展示；渠道维度固定显示 `-` |
| 总收入 | 全部已结算的结算收入 − 全部已结算的结算退款；固定 ￥ |
| 累计实际付款金额 | 游戏、厂商维度累计游戏付款管理全部已付款记录的「实际付款金额」；固定 ￥，不包含申请付款时直接抵扣的预付分成款；渠道维度固定显示 `-` |

统计对象为当前业务类型下存在已结算收入或退款记录的游戏、渠道和厂商。合同已付款金额是合同当前累计快照，不是按日期追溯的付款流水。

游戏ID / 游戏名称：左边游戏 ID，右边游戏名称。
