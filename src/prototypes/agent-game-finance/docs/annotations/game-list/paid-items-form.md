# 已付款项表单

## 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 游戏ID / 游戏名称 | — | 只读 |
| 合同编号 | — | 只读 |
| 已付游戏代理金 | 合同勾选游戏代理金时必填 | 两位小数，不小于 0 |
| 已付预付分成款 | 合同勾选预付分成款时必填 | 两位小数，不小于 0 |
| 已付委托开发费 | 合同勾选委托开发费时必填 | 两位小数，不小于 0 |

金额前缀取合同支付币种。未被合同勾选的合作内容不显示对应字段。

## 保存规则

必填未齐 → 红色提示 + 「请完善所有信息」。  
保存成功 → 关闭抽屉 + 绿色「提交成功」；列表、汇总、导出与操作记录同步使用最新金额。
