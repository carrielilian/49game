# 已付款项表单

## 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 游戏ID / 游戏名称 | — | 只读 |
| 合同编号 | — | 只读 |
| 已付游戏代理金 | 合同勾选游戏代理金时必填 | 两位小数，不小于 0；大于等于当前已保存金额，且小于等于合同约定的游戏代理金 |
| 已付预付分成款 | 合同勾选预付分成款时必填 | 两位小数，不小于 0；大于等于当前已保存金额，且小于等于合同约定的预付分成款 |
| 已付委托开发费 | 合同勾选委托开发费时必填 | 两位小数，不小于 0；大于等于当前已保存金额，且小于等于合同约定的委托开发费 |

金额前缀取合同支付币种。未被合同勾选的合作内容不显示对应字段。默认只显示原有灰色字段说明，不提前展示历史金额或递增限制。

## 保存规则

必填未齐、格式不正确、本次金额小于当前已保存金额或超过对应合同约定金额 → 字段红色提示 + 「请完善所有信息」。金额超过合同约定值时提示“{已付字段名称}不能大于合同约定的{合作内容名称}”；金额递增校验提示“本次提交金额需大于等于历史金额”。
保存成功 → 关闭抽屉 + 绿色「提交成功」；列表、汇总、导出与操作记录同步使用最新金额。
