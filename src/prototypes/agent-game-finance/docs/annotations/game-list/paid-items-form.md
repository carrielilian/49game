# 已付款项表单

## 字段

| 字段 | 必填 | 说明 |
|------|------|------|
| 游戏ID / 游戏名称 | — | 只读 |
| 合同编号 | — | 只读 |
| 已付游戏代理金 | 合同勾选游戏代理金时必填 | 两位小数，不小于 0；已保存过时，本次提交金额必须大于当前已保存金额 |
| 已付预付分成款 | 合同勾选预付分成款时必填 | 两位小数，不小于 0；已保存过时，本次提交金额必须大于当前已保存金额 |
| 已付委托开发费 | 合同勾选委托开发费时必填 | 两位小数，不小于 0；已保存过时，本次提交金额必须大于当前已保存金额 |

金额前缀取合同支付币种。未被合同勾选的合作内容不显示对应字段。默认只显示原有灰色字段说明，不提前展示历史金额或递增限制。

## 保存规则

必填未齐、格式不正确或本次金额未大于当前已保存金额 → 字段红色提示 + 「请完善所有信息」。其中金额递增校验仅在点击【保存】时触发，并在灰色说明下方显示“本次提交金额需大于历史金额”。
保存成功 → 关闭抽屉 + 绿色「提交成功」；列表、汇总、导出与操作记录同步使用最新金额。
