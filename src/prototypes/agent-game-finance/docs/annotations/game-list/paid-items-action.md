# 已付款项

## 做什么

打开「已付款项」抽屉，维护当前游戏合同中已经支付的游戏代理金、预付分成款和委托开发费。

## 不同情况怎么展示

| 情况 | 页面表现 |
|------|----------|
| 已维护合同 | 打开抽屉，仅显示合同已勾选合作内容对应的已付金额 |
| 尚未维护合同 | 不打开抽屉，提示「请先维护合同信息」 |
| 本次提交金额小于或等于当前已保存金额 | 点击【保存】后阻止提交，在对应字段的灰色说明下方提示「本次提交金额需大于历史金额」 |
| 保存成功 | 关闭抽屉，列表三项已付列同步更新，弹出绿色「提交成功」 |
| 必填未填 | 字段红色提示 + 「请完善所有信息」 |

详细字段见 **已付款项表单** 批注。
