# 付款设置抽屉

## 区块一：预付分成管理

| 字段 | 规则 |
|------|------|
| 游戏ID / 游戏名称 | 只读；左边游戏 ID，右边游戏名称；打开抽屉时展示当前游戏 |
| 有无预付分成款 * | 单选“有 / 无”；选择“有”时显示下方两个字段，选择“无”时隐藏 |
| 预付分成款 | 选择“有”时显示；只读；取【游戏管理 → 已付款项】的“已付预付分成款”（`Contract.paidPrepayment`）；币种取合同支付币种；未设置显示「-」 |
| 历史已抵扣分成款 * | 选择“有”时显示并必填；精确至小数点后两位；下方提示「请填写线下已抵扣处理的预付分成款，若无则填写0」 |

抽屉不显示“已抵扣分成款”和“剩余未抵扣分成款”；这两个值仍在列表及后续付款计算中使用。

## 区块二：付费设置

| 字段 | 规则 |
|------|------|
| 分成付款公司 * | 4399 / 纯游 / 纯游（美元） / 香港4399 / 游家时代。**初始**：未保存过为空（显示「请选择」）；已保存过显示已选项 |
| 付款币种 * | 人民币 / 美金 单选。**初始**：未保存过默认选中「人民币」；已保存过显示已选项 |

## 按钮

| 按钮 | 行为 |
|------|------|
| 取消 | 关闭，不保存 |
| 保存 | 校验通过后关闭；绿色「提交成功」 |

选择“有”时校验历史已抵扣分成款；选择“无”时不校验并按预付 0 参与后续计算。分成付款公司和付款币种始终必填。校验失败：字段下红字 + 红 Toast「请完善所有信息」。
