# 申请付款确认

## 做什么

二次确认本次申请付款金额。

## 文案

固定显示：申请付款金额：{余额}元。不展示收入或退款未结算提醒。

## 填写字段

| 字段 | 规则 |
|------|------|
| 汇率取值时间 * | 日历日期选择器；必填；精确至天；打开弹窗默认当天；输入框带日历图标，点击展开单月日历，可切换月/年 |
| 汇率 * | 必填；允许输入正整数或正数小数，最多四位小数；失焦后统一补齐四位小数，例如输入“7”后显示“7.0000” |

确认申请时同时冻结这两个字段。游戏付款管理的标记付款、实际付款金额换算和结算函均优先使用本次填写的汇率。

## 按钮

| 按钮 | 行为 |
|------|------|
| 取消 | 关闭 |
| 确认申请 | 见下方成功逻辑 |

## 确认申请成功

1. 绿色提示「申请付款成功，账户余额已清零」
2. 按申请时刻信息固定保存本笔付款与结算函（详见「申请付款」批注）
3. 在「游戏付款管理」主列表**最上方**新增「未付款」记录
4. 本次纳入的结算明细改为「已申请」

失败（余额 ≤ 0）：红色提示「账户余额不足，无法申请」。
