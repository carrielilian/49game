# 字段说明

## 做什么

面包屑标题右侧 **?** 图标，点击弹出各金额字段计算口径。

## 说明条目

1. 账户总收入 ＝ 累计收入 − 累计退款
2. 账户余额 ＝ 收入结算「未申请」结算收入之和 − 退款结算「未申请」结算退款之和（按游戏）
3. 预付分成款 ＝ 【游戏管理 → 已付款项】的“已付预付分成款”
4. 已抵扣分成款 ＝ 历史已抵扣分成款 + 历次付款申请成功时直接抵扣的预付分成款；最大不超过预付分成款
5. 剩余未抵扣分成款 ＝ 预付分成款 − 已抵扣分成款（≤ 0 时为 0）
6. 累计收入 ＝ 收入结算全部已结算「结算收入」之和
7. 累计退款 ＝ 退款结算全部已结算「结算退款」之和
