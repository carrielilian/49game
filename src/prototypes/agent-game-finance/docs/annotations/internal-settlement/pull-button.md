## 规则

| 情况 | 页面表现 |
|------|----------|
| 每月首次进入 | 按钮可点，「结算」按钮置灰 |
| 财务中心的收入结算列表，4399和快爆两个平台下存在游戏业务类型还没点击结算按钮 | 红色「财务中心还未结算完成」 |
| 拉取成功 | 绿色「已从财务中心拉取待结算数据」；「结算」变为可点；本页「数据拉取」置灰 |
| 同月再次进入 | 拉取成功后本页「数据拉取」保持置灰 |

## 数据来源

按【结算配置管理 → 数据拉取】中已勾选的渠道及对应渠道游戏ID，从财务中心取数。拉取记录的「收入时间」为上月（YYYY-MM）。
