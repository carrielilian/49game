# 退款结算列表

## 做什么

展示系统拉取的自有渠道及外部关联平台待结算、已结算退款记录。

## 各列含义

| 列 | 说明 |
|----|------|
| 退款时间 | 拉取数据的月份（YYYY-MM） |
| 游戏ID / 游戏名称 | 左边游戏 ID，右边游戏名称 |
| 厂商编号、厂商名称 | 归属厂商，分两列 |
| 渠道 | 见 **渠道列** 批注 |
| 退款金额 | 人民币 + 千分位；沿用 `settlementAmount` 数据字段 |
| 结算退款 | 未结算显示「-」；已结算显示人民币 + 千分位 |
| 结算公式 | 自有渠道取自有渠道公式，外部关联平台取外部渠道公式；变量名称显示为“退款金额” |
| 结算时间 | 未结算「-」；已结算为点击「结算」的时间 |
| 申请付款状态 | 见 **申请付款状态列** 批注 |
