# 结算

## 做什么

对主列表中**当前未结算**的行批量完成结算，写入结算退款与结算时间。

## 规则

| 情况 | 页面表现 |
|------|----------|
| 当前查询范围无未结算记录 | 按钮置灰不可点 |
| 当前查询范围存在未结算记录 | 按钮可点，不依赖是否刚执行数据拉取 |
| 存在游戏缺少适用公式 | 整批不结算，提示「{游戏ID}缺少结算公式」（多个ID去重后用「、」连接） |
| 任一记录校验或计算失败 | 整批不结算，提示「结算失败，本次数据均未结算：{原因}」 |
| 结算成功 | 绿色「结算成功」；未结算行的结算退款、结算时间更新；本页「结算」置灰 |

自有渠道取自有渠道公式，外部关联平台取外部渠道公式。结算按整批原子处理：全部记录校验通过才一次性写入；任一失败时所有记录均保持未结算。
