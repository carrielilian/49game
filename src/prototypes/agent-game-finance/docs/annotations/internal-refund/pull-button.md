## 规则

| 情况 | 页面表现 |
|------|----------|
| 每月首次进入 | 数据拉取按钮可点 |
| 财务中心的退款结算列表，快爆平台下存在游戏业务类型还没点击结算按钮 | 红色「财务中心还未结算完成」 |
| 拉取成功 | 绿色「已从财务中心拉取待结算数据」；存在未结算记录时「结算」可点；本页「数据拉取」置灰 |
| 同月再次进入 | 拉取成功后本页「数据拉取」保持置灰 |

## 数据来源

按【结算配置管理 → 数据拉取】中已勾选的渠道及对应渠道游戏ID，从财务中心取数。拉取记录的「退款时间」为上月（YYYY-MM）。

- 自有渠道拉取财务中心原始“退款金额”。
- 外部渠道拉取财务中心已经按其结算公式计算后的金额，即“退款金额 × 财务中心结算公式”。
- 上述拉取结果统一写入本页“退款金额”列并置于列表最上方；未结算时“结算公式”显示「-」。点击【结算】时，两类渠道均使用本系统外部渠道公式中的扣税点与分成计算“结算退款”，不扣渠道费。
