# 编辑厂商表单

## 表单结构

与添加表单布局相同，分为「厂商信息」和「银行信息」两块，内容来自当前正在编辑的那一行。

### 厂商信息

| 字段 | 是否必填 | 编辑时怎么展示 |
|------|----------|----------------|
| 厂商编号 | 否（只读） | 显示当前编号，不可修改 |
| 厂商名称 | 必填 | 可改，默认是列表里的名称 |
| 联系人 | 选填 | 可改 |
| 手机 | 选填 | 可改 |
| 邮箱 | 选填 | 可改 |
| 单位地址 | 选填 | 可改 |
| 发票信息 | 必填 | 下拉，默认是列表里的类型；若修改，可能影响该厂商相关结算公式中的扣税点展示 |
| 扣税点 | 条件必填 | 发票信息为“其他”时显示并回显，位于厂商信息第二行、发票信息右侧；输入 0–100，最多两位小数，金额0视为有效 |

### 银行信息

第一行展示开户名称、开户银行、开户银行所在地；第二行展示支行名称、银行卡号、银行代码。

开户名称、开户银行、开户银行所在地、支行名称、银行卡号均为必填，银行代码选填；所有银行信息字段均为文本输入且可编辑。

## 保存规则

基础七项必填：厂商名称、发票信息，以及银行信息五项。联系人、手机、邮箱、单位地址可以不填；发票信息选择“其他”时，扣税点额外必填。

| 情况 | 页面表现 |
|------|----------|
| 必填项为空 | 该字段下方显示「某某不能为空」类红色提示 |
| 点保存但未通过校验 | 抽屉保持打开，并弹出「请完善所有信息」 |
| 保存成功 | 关闭抽屉，列表该行更新，厂商编号不变，并弹出绿色「提交成功」 |

## 业务说明

- 编辑不能改厂商编号，也不能把厂商挪到另一个业务类型（游戏盒 / 快爆）。
- 若改了发票信息，该厂商旗下游戏在「结算配置管理」中展示的扣税点随之变化；发票选择“其他”时，读取本表单维护的扣税点。
