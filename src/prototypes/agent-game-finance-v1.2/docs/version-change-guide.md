# V1.2 版本变更标注规则

- 比较基线：V1.1。
- 变更中心只登记 V1.2 新增或调整的需求，不重复登记 V1.1 已有功能。
- 每条记录必须包含需求编号、变更类型、调整前规则、调整后规则、影响页面、验收标准和实现状态。
- 页面定位使用现有 `data-annotation-id`，纯逻辑变化标在触发规则的按钮、字段、表格或页面标题旁。
- 新增为绿色，调整为蓝色，规则变化为橙色；删除只在变更中心显示红色标识。
- 页面标识默认开启，用户可从顶部关闭；关闭只隐藏标识，不改变业务功能。
- V1.2 不展示 V1.1 继承下来的旧批注入口和批注序号，避免把完整功能说明误认为本次版本变化；完整批注在 V1.1 原型中查阅。
- 旧批注使用的稳定 `data-annotation-id` 只作为变更标识定位依据保留，不在 V1.2 页面展示。

当前 V1.2 尚未收到已确认的新业务需求，因此变更清单为空。
