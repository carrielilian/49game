# 数据拉取

## 做什么

根据渠道游戏ID，从【财务中心－结算管理－游戏收入结算】拉取自有渠道和外部渠道数据，最终按“月 + 游戏ID + 汇总渠道”汇总为一条收入记录，写入统一主列表。

| 渠道归属 | 取值字段 | 结算公式 |
|----------|----------|----------|
| 自有渠道 | 待结算金额 | 自有渠道结算公式 |
| 外部渠道－系统拉取的外部渠道 | 结算收入 | 外部渠道结算公式 |

游戏盒业务以“游戏盒”为自有渠道、“快爆”为外部渠道；快爆业务反向。拉取成功的数据写入统一收入主列表最上方，初始为未结算，结算收入、结算公式和结算时间显示“-”。

## 拉取结果

| 情况 | 页面表现 |
|------|----------|
| 财务中心还未结算完成 | 红色提示“财务中心还未结算完成”；【数据拉取】保持可点击 |
| 没有匹配的可拉取数据 | 红色提示“暂无可拉取数据”；不写入列表，不记录拉取成功，【数据拉取】保持可点击 |
| 拉取到数据 | 绿色提示“已从财务中心拉取待结算数据”；数据写入列表，【数据拉取】置灰 |
